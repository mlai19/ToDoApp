# To-Do App  

A simple **JavaScript To-Do List App** that allows users to organize and manage daily tasks with categories, live date/time display, and persistent storage via `localStorage`.  

## 🚀 Tech Stack  
- HTML  
- CSS  
- Vanilla JavaScript  

## ⚡ Features  
- Add, delete, and check off tasks  
- Organize tasks by category (Work, Personal, Shopping, etc.)  
- Displays today’s date and live time  
- Persists tasks in browser `localStorage`  
- Responsive, mobile-friendly UI  

## ▶️ How to Run  
Just open `index.html` in your browser — no server setup required.  

## 📚 Learning  
I built this project by following a tutorial to strengthen my **JavaScript fundamentals**, especially:  
- DOM manipulation  
- Event handling  
- `localStorage` for persistence  
- Responsive design with CSS
